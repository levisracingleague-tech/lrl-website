# Levi's Racing League Website v2

Official GitHub Pages website for Levi's Racing League.

## New in v2

- Secure Supabase admin login
- Team management
- Driver standings management
- Live public website data
- Discord server widget
- Static fallback when the database is not connected

## Upload

Upload every file and folder from this package to the root of the existing GitHub Pages repository. Replace older files.

Then follow:

```text
README_ADMIN.md
```

The site remains usable before Supabase is connected. Teams use the static fallback and standings show the pre-season message.
